# Security

This is an early proof of concept. It starts `codex app-server` locally and can operate approved desktop apps through the configured Computer Use connection. It does not provide unattended operation, remote control, or a security boundary around the desktop apps it can access.

Please report a security issue privately through GitHub's **Report a vulnerability** option on this repository. Avoid posting credentials, private screenshots, or reproduction data in a public issue.

The supported version is the latest commit on `main`; there are no released versions yet.
